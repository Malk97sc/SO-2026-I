# Evaluaciones y Retroalimentación

Este directorio contiene las soluciones y retroalimentación de los diversos talleres y exámenes parciales realizados durante el semestre. El objetivo de este espacio es permitir a los estudiantes revisar las implementaciones esperadas, entender los errores comunes y consolidar los conceptos evaluados.

## Estructura

- **[Talleres](talleres/)**: Soluciones detalladas a los talleres prácticos de cada corte.
  - **Corte 2**: Ejercicios de procesos e IPC.
  - **Corte 3**: Ejercicios de hilos y sincronización.
- **[Parciales](parciales/)**: Resolución de los exámenes parciales aplicados a los diferentes grupos, incluyendo archivos de prueba (`.in`) utilizados para la calificación.

## Propósito
Cada solución está diseñada para servir como guía de estudio, mostrando buenas prácticas de programación en C y el uso correcto de las APIs de sistemas operativos.
