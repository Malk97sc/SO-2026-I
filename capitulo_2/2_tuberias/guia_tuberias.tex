\section{Motivación}
Gran parte del poder de la terminal de Linux reside en el operador \texttt{|}. Este permite conectar la salida de un proceso con la entrada de otro. Internamente, esto se logra mediante el mecanismo de \textbf{Pipes}.

\section{Idea Fundamental}
Un pipe es un buffer circular en el espacio del kernel que permite el flujo de datos en una sola dirección. Para que dos procesos se comuniquen mediante un pipe, deben tener un ancestro común que haya creado el pipe antes de realizar un \texttt{fork()}.

\section{Sintaxis Básica}
\begin{lstlisting}[numbers=none]
#include <unistd.h>
int fd[2];
pipe(fd); // Creates the pipe. 
          // fd[0]: Read end
          // fd[1]: Write end
\end{lstlisting}

\paragraph{Descripción de las operaciones}
\begin{itemize}
    \item \textbf{pipe(fd):} Crea un canal de comunicación y llena el arreglo \texttt{fd} con dos descriptores de archivo. Devuelve 0 en éxito y -1 en error.
    \item \textbf{write(fd[1], buf, n):} Envía \texttt{n} bytes desde el buffer \texttt{buf} hacia el pipe. Si el pipe está lleno, el proceso se bloquea.
    \item \textbf{read(fd[0], buf, n):} Lee hasta \texttt{n} bytes del pipe y los guarda en \texttt{buf}. Si el pipe está vacío, el proceso se bloquea hasta que haya datos.
    \item \textbf{close(fd):} Cierra un extremo del pipe. Es \textbf{crítico} cerrar los extremos no utilizados en cada proceso para que \texttt{read()} pueda detectar el final del archivo (EOF) cuando todos los escritores cierren el pipe.
\end{itemize}

\section{Ejemplo: Comunicación Padre-Hijo}
En este ejemplo, el padre envía un mensaje al hijo. Note cómo cada proceso cierra el extremo que no va a utilizar inmediatamente después del \texttt{fork()}.

\begin{lstlisting}
#include <stdio.h>
#include <unistd.h>
#include <string.h>
#include <sys/wait.h>

int main() {
    int fd[2];
    char buffer[30];

    if(pipe(fd) == -1){
        perror("pipe");
        return 1;
    }

    if(fork() > 0){ // Parent process
        close(fd[0]); // Parent will not read, close read end
        
        char msg[] = "Message from your parent!";
        write(fd[1], msg, strlen(msg) + 1);
        
        close(fd[1]); // Finished writing
        wait(NULL);   // Wait for child to finish
    }else{ // Child process
        close(fd[1]); // Child will not write, close write end
        
        read(fd[0], buffer, sizeof(buffer));
        printf("Child received: %s\n", buffer);
        
        close(fd[0]); // Finished reading
    }
    return 0;
}
\end{lstlisting}

\section{Conceptos Avanzados}
\begin{itemize}
    \item \textbf{Tuberías con nombre (FIFOs):} A diferencia de los pipes anónimos, los FIFOs tienen un nombre en el sistema de archivos y permiten la comunicación entre procesos sin parentesco.
\end{itemize}
