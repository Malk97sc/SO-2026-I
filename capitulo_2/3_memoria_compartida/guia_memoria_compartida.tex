\section{Motivación}
Cuando necesitamos transferir grandes volúmenes de datos entre procesos de manera ultra-rápida, los pipes son lentos porque implican copiar datos entre el espacio de usuario y el kernel. La \textbf{Memoria Compartida} permite que dos procesos mapeen la misma región de memoria física a su espacio de direcciones virtual.

\section{Idea Fundamental}
Normalmente, el kernel garantiza que un proceso no pueda acceder a la memoria de otro. La memoria compartida es una excepción controlada:

\begin{enumerate}
    \item Se crea un segmento de memoria en el kernel.
    \item Cada proceso lo "mapea" (adjunta) a su propio espacio virtual.
    \item Los procesos leen y escriben como si fuera memoria local normal.
\end{enumerate}

\section{Sintaxis (Estilo System V)}
\begin{lstlisting}[numbers=none]
#include <sys/shm.h>
#include <sys/ipc.h>

// 1. Get identifier (Create segment)
int shmid = shmget(key, size, IPC_CREAT | 0666);

// 2. Attach to process address space
void *ptr = (void *)shmat(shmid, NULL, 0);

// 3. Detach when finished
shmdt(ptr);

// 4. Control/Removal
shmctl(shmid, IPC_RMID, NULL);
\end{lstlisting}

\paragraph{Descripción de las operaciones}

\begin{itemize}
    \item \textbf{shmget():} Crea u obtiene un segmento de memoria compartida identificado por una clave (\textit{key}). Devuelve un identificador del segmento (\textit{shmid}) que será utilizado en las operaciones posteriores.

    \item \textbf{shmat():} Adjunta el segmento de memoria compartida al espacio de direcciones del proceso y devuelve un puntero que permite acceder a dicha memoria como si fuera memoria normal.

    \item \textbf{shmdt():} Desvincula el segmento de memoria compartida del proceso una vez que este ha terminado de utilizarlo.

    \item \textbf{shmctl():} Permite realizar operaciones de control sobre el segmento; comúnmente se usa con \texttt{IPC\_RMID} para marcar el segmento para su eliminación del sistema.
\end{itemize}

\section{Ejemplo: Contador Compartido}
Este ejemplo muestra la creación de un segmento para un entero compartido que es modificado por un proceso padre y su hijo simultáneamente.

\begin{lstlisting}
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/wait.h>
#include <sys/shm.h>
#include <sys/stat.h>

int main() {
    int shmid, *counter;
    int max_iter = 1000000;

    // Create shared memory segment (System V)
    shmid = shmget(IPC_PRIVATE, sizeof(int), 0666 | IPC_CREAT);
    counter = (int *)shmat(shmid, NULL, 0);
    *counter = 0;

    if(fork()){ // Parent process
        for(int i=0; i < max_iter; i++){
            *counter = *counter + 1;
        } 

        wait(NULL);
        printf("Final value of counter: %d\n", *counter);

        shmdt(counter); // Detach from process address space
        shmctl(shmid, IPC_RMID, NULL); // Remove shared memory segment
        
    }else{// Child process
        for (int i = 0; i < max_iter; i++) *counter = *counter + 1;

        shmdt(counter); // Detach from process address space
    }

    return EXIT_SUCCESS;
}
\end{lstlisting}

\section{Precaución: El Problema de la Carrera}
La memoria compartida \textbf{no tiene sincronización automática}. Si ambos procesos escriben al mismo tiempo (como en el ejemplo anterior), el resultado final podría no ser el esperado debido a condiciones de carrera. Para esto necesitaremos algún mecanismo de sincronización.
