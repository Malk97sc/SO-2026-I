\section*{Introducción}
Este taller se enfoca en la coordinación asíncrona de procesos mediante el uso de señales POSIX (\texttt{SIGUSR1}, \texttt{SIGUSR2}). El objetivo es controlar el orden de ejecución de una jerarquía de procesos para que sigan una secuencia.

\section*{Bloque 1: De Diagramas a Código}
\textit{Desarrolle el código necesario para replicar las siguientes estructuras y secuencias de señales. Todos los procesos deben imprimir su letra correspondiente al recibir o enviar el control.}

\subsection*{Ejercicio 4}
Analice el siguiente código y determine la salida exacta por consola. Asuma que \texttt{fork()} tiene éxito y que el proceso padre siempre inicia la ejecución.

\begin{lstlisting}
void handler(int sig) { /* Despierta el proceso */ }

int main(){
    signal(SIGUSR1, handler);
    pid_t p1, p2;
    p1 = fork();
    if(p1 == 0){
        pause();
        printf("H1\n");
        kill(getppid(), SIGUSR1);
        exit(0);
    }
    p2 = fork();
    if(p2 == 0){
        printf("H2\n");
        kill(getppid(), SIGUSR1);
        exit(0);
    }
    pause();
    kill(p1, SIGUSR1);
    pause();
    printf("Padre\n");
    return 0;
}
\end{lstlisting}
