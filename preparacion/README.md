# Área de Preparación

Este espacio está reservado para la realización de actividades previas a las evaluaciones del curso de Sistemas Operativos. El objetivo es proporcionar un entorno de práctica que integre todos los conocimientos adquiridos en los capítulos anteriores.

## Contenido

- **[Pre-Talleres](pre_talleres/)**: Ejercicios de mayor envergadura diseñados para imitar la estructura y dificultad de los talleres evaluativos del semestre.
- **[Pre-Parciales](pre_parciales/)**: Colección de problemas prácticos y teóricos extraídos de exámenes de semestres anteriores para practicar bajo condiciones de parcial.
