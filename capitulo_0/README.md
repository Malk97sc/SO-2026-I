# Capítulo 0: Fundamentos de la Programación en C

Este capítulo cubre los conceptos esenciales de la programación en C necesarios para el curso de Sistemas Operativos. Incluye guías teóricas, ejemplos prácticos de código y una prueba diagnóstica para evaluar el conocimiento inicial.

## Contenido

### 1. Flujo de Control

Se enfoca en la toma de decisiones y los bucles.

### 2. Funciones

Cubre la modularidad y la pila (stack).

### 3. Punteros (Pointers)

El núcleo del lenguaje C y la gestión manual de memoria.

### 4. Memoria Dinámica

Introducción al heap y a la asignación manual de memoria.

### 5. Archivos

Persistencia de datos e interacción con el sistema de archivos.

### 6. Ejercicios Propuestos

Una serie de ejercicios para practicar los conceptos vistos.

### 7. Prueba Diagnóstica

Una evaluación inicial para verificar la preparación para temas más avanzados.

## Cómo Compilar

Para ejecutar los ejemplos de código, navega al directorio `codes/` y usa `gcc`:

```bash
gcc ejercicio1.c -o exercise1
./exercise1
```
