# Capítulo 2: Comunicación entre Procesos (IPC)

Este capítulo introduce los mecanismos necesarios para la interacción y el intercambio de información entre procesos en sistemas operativos basados en POSIX.

## Contenido

### 1. Señales (`signals`)

Explica cómo notificar a un proceso sobre eventos asíncronos en el sistema. Uso de la señalización para interrumpir, terminar o reanudar procesos.

### 2. Tuberías (`pipes`)

Introduce el concepto de flujo de datos entre procesos. Uso de tuberías anónimas para conectar la salida de un proceso con la entrada de otro.

### 3. Memoria Compartida (`shm`)

Implementación de regiones de memoria accesibles para múltiples procesos, permitiendo una comunicación de alta velocidad.

## Ejercicios Propuestos

Este apartado contiene una serie de talleres prácticos para reforzar los conceptos de cada módulo.
