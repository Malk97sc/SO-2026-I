\section{Motivación}
En un sistema con cientos de procesos corriendo al mismo tiempo, el Sistema Operativo necesita una forma única de etiquetar y rastrear cada uno de ellos. Al igual que nosotros tenemos una identificación personal, cada proceso tiene un número único que permite enviarle señales, esperar por él o conocer quién lo creó.

\section{Idea Fundamental}
Todo proceso en POSIX tiene dos identificadores clave: su propio ID (\textbf{PID}) y el ID de su creador o padre (\textbf{PPID}). Estas ``etiquetas'' son números enteros de tipo \texttt{pid\_t}.

\section{Sintaxis Básica}
\begin{lstlisting}[numbers=none]
#include <unistd.h>
#include <sys/types.h>

pid_t my_pid = getpid();   // Obtiene el PID del proceso actual
pid_t my_ppid = getppid(); // Obtiene el PID del proceso padre
\end{lstlisting}

\section{Ejemplo Mínimo Funcional}
\begin{lstlisting}
#include <stdio.h>
#include <unistd.h>

int main() {
    printf("Self PID: %d\n", getpid());
    printf("Parent PID: %d\n", getppid());

    if(fork() == 0){
      printf("[CHILD] PID: %d, PPID: %d\n", getpid(), getppid());
    }else{
      printf("[PARENT] PID: %d, PPID: %d\n", getpid(), getppid());
    }
    return 0;
}
\end{lstlisting}

\section{Explicación Paso a Paso}
\begin{enumerate}
    \item El programa inicia e imprime sus propios datos.
    \item Se ejecuta \texttt{fork()} creando un hijo.
    \item El hijo imprime su PID (nuevo) y su PPID (que será el PID del padre).
    \item El padre imprime su PID y su PPID (posiblemente la \textit{shell} desde donde se ejecutó).
\end{enumerate}

\section{Qué ocurre en memoria}
El Sistema Operativo mantiene una \textbf{Tabla de Procesos}. Cada entrada en esta tabla contiene el PID, PPID, estado de ejecución y otros metadatos (el PCB - Process Control Block). Las funciones \texttt{getpid} y \texttt{getppid} simplemente consultan esta tabla para el proceso que las llama.

\section{Patrones comunes de uso}
Rastreo de jerarquía para depuración:
\begin{lstlisting}
void log_context(char *msg) {
    printf("[%s] PID: %d (PPID: %d)\n", msg, getpid(), getppid());
}
\end{lstlisting}

\section{Errores Comunes}
\begin{itemize}
    \item \textbf{PPID = 1:} Si el padre termina antes que el hijo, el PPID del hijo cambiará automáticamente a 1 (adoptado por \textit{init}).
    \item \textbf{Confusión con retornos:} No confundir el valor de retorno de \texttt{fork()} con el resultado de \texttt{getpid()}.
\end{itemize}

\section{Buenas Prácticas}
\begin{itemize}
    \item No hardcodear PIDs (ej: \texttt{kill(1234, ...)}); siempre obtenerlos dinámicamente.
    \item Usar PIDs en los nombres de archivos temporales o \textit{logs} para evitar colisiones entre procesos.
\end{itemize}

\section{Ejercicios}
\begin{enumerate}
    \item Escriba un programa que cree un hijo y un nieto. Cada uno debe imprimir su PID y el de su padre.
    \item Verifique desde la terminal cuál es el PID de su Shell (\texttt{echo \$\$}) y compárelo con el PPID que reporta su programa al iniciar.
\end{enumerate}
