# Plantillas de Código

Este directorio contiene fragmentos de código reutilizables,diseñados para agilizar el desarrollo de laboratorios y ejercicios prácticos en la asignatura de Sistemas Operativos.

Las plantillas están organizadas por temas y proporcionan la lógica estructural básica (manejo de procesos, memoria dinámica, etc.) para que el estudiante pueda centrarse en la lógica específica de cada problema.

## Contenido de las Plantillas

### 1. Gestión de Procesos (`fork/`)

Estructuras comunes para la creación de jerarquías de procesos en sistemas POSIX.

### 2. Memoria y Archivos (`archivos/`)

Lectura de archivos y manejo de memoria dinámica.

**Nota**: Todas las plantillas están pensadas para ser ejecutadas en entornos compatibles con POSIX (Linux).
